# Service Fediverse

Service indépendant prévu pour l'interopérabilité sociale via ActivityPub.

## Portée initiale

- Acteurs publics pour joueurs (opt-in), personnages et guildes.
- WebFinger et ActivityPub.
- Publications de succès, événements et annonces.
- Abonnements et notifications.
- Outils de modération, blocage et suppression.

## Non-objectifs initiaux

ActivityPub ne sera pas utilisé pour transporter l'état temps réel du jeu, les inventaires, les positions ou les identifiants de connexion. Les profils publics ne doivent pas exposer d'adresse e-mail ou de données privées.

Aucun code de fédération n'est encore implémenté.
