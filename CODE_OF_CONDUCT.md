# Code de conduite

Nous voulons une communauté accueillante, familiale et constructive.

## Nos engagements

- Respecter les personnes, leurs expériences et leurs différences.
- Être bienveillant dans les échanges et accepter les désaccords argumentés.
- Accueillir les débutants et expliquer les choix techniques sans condescendance.
- Garder l'humour dans le cadre du jeu ; pas de harcèlement, de discrimination ni d'attaques personnelles.
- Protéger les mineurs et ne pas solliciter ni publier leurs informations personnelles.

## Comportements inacceptables

Harcèlement, menaces, intimidation, doxxing, discrimination, contenu sexuel impliquant des mineurs, publication de données privées ou comportement volontairement perturbateur.

## Application

Les responsables du projet peuvent éditer ou supprimer les contenus contraires à ce code, avertir les personnes concernées ou les exclure des espaces communautaires. Les signalements doivent être adressés en privé aux mainteneurs du dépôt.

Ce code s'applique aux issues, pull requests, discussions, espaces communautaires officiels et événements du projet.
