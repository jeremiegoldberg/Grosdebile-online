# Sommières géoréférencée — GDO

Le patch remplace l'ancienne génération manuelle de la ville par le renderer GIS v2.

- 815 emprises bâties et 226 tronçons routiers ;
- 4 zones d'eau et 2 axes hydrographiques ;
- 454 arbres et 164 points d'intérêt ;
- relief RGE ALTI échantillonné sur une grille 28 × 29 ;
- atlas de textures original 64 × 64.

Les sources citées dans le relevé sont IGN BD TOPO / RGE ALTI, OpenStreetMap et une extraction MNS pour les arbres. Les conditions de redistribution de chaque jeu de données doivent être vérifiées avant diffusion publique du monde.

**Avant mise à jour : sauvegarde le monde.** La version 6 reconstruit l'emprise de Sommières au premier lancement. Le château et les villages de guildes restent hors de cette emprise.

Commandes : `/gdo_city`, `/gdo_castle`, `/gdo_city_info`, `/gdo_city_rebuild`.
