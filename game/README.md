# Jeu Luanti

Le jeu principal sera installé sous `game/gdo/` et utilisera l'identifiant Luanti `gdo`.

Le prototype devra être autonome autant que possible, avec ses propres textures et dépendances explicitement documentées. Aucun contenu tiers ne sera intégré sans vérification de licence.

Le serveur reste autoritaire pour les actions de gameplay. Les interfaces et contrôles doivent anticiper PC, Android et l'expérimentation VR.
