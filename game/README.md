# Jeu Luanti GDO

Le jeu autonome est installé sous `game/gdo/` avec l'identifiant Luanti `gdo`.

## Prototype actuel

- Le jeu ne dépend pas de Minetest Game ni d'un mod externe.
- `gdo_core` construit une petite clairière de départ.
- Gérard le Magnifique donne la première quête.
- Le joueur récolte trois navets héroïques et reçoit le Badge officiel du Nawak.
- Les données de quête sont conservées dans les métadonnées du joueur.

Les textures sont pour le moment des textures de remplacement basées sur les ressources intégrées de Luanti. Elles seront remplacées par les assets originaux du projet.

Pour installer et lancer le jeu sous Linux : [docs/quickstart-linux.md](../docs/quickstart-linux.md).

Cette version est un prototype technique non encore validé sur une machine de test indépendante.
