# Contribuer à Gros Débile Online

Merci de vouloir contribuer au Royaume du Nawak !

## Avant de commencer

1. Ouvrir ou consulter une issue pour discuter des changements importants.
2. Vérifier les licences et la provenance de tout code, texte, modèle, texture, son ou autre ressource ajoutée.
3. Ne jamais ajouter de données personnelles, secrets, mots de passe, clés, sauvegardes de mondes privés ou données de joueurs.

## Types de contributions

- Gameplay Lua et intégration Luanti
- Backend Go et migrations SQL
- Cartes, biomes, structures, donjons et quêtes
- Modèles, textures, animations et sons
- Documentation, traductions, tests et accessibilité

## Règles de contribution

- Une modification cohérente par pull request.
- Décrire le problème, la solution et les impacts.
- Ajouter ou adapter les tests lorsqu'ils existent.
- Préserver la compatibilité PC/Android ; signaler les impacts VR.
- Éviter les dépendances inutiles et documenter les dépendances ajoutées.
- Pour les assets, joindre la source, l'auteur, la licence et les éventuelles modifications dans un fichier de crédits.

## Licences et droits

En soumettant une contribution, vous confirmez avoir le droit de la publier sous la licence applicable au répertoire concerné : AGPL-3.0-or-later pour le code, CC-BY-SA-4.0 pour les contenus originaux, sauf exception explicitement documentée. N'importez pas de contenus extraits de jeux commerciaux ou d'assets dont la licence est inconnue.

## Pull requests

Utiliser des titres explicites, par exemple :

- `game: add first village NPC prototype`
- `backend: add character profile endpoint`
- `world: document the first region`
- `docs: describe ActivityPub actor model`

Le projet est en phase initiale : les conventions techniques pourront évoluer via des décisions documentées.
