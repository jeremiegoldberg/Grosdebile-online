# Signaler une vulnérabilité

Ne publiez pas de vulnérabilité exploitable dans une issue publique.

Pour le moment, contactez les mainteneurs via les moyens privés proposés par GitHub sur le dépôt. Une adresse dédiée de sécurité sera publiée avant l'ouverture du serveur public.

Merci d'inclure :
- le composant et la version concernés ;
- les étapes de reproduction ;
- l'impact potentiel ;
- une preuve de concept non destructive si possible.

Ne joignez jamais de données personnelles réelles, de mots de passe ou de secrets.
